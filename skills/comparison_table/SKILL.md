# 对比类查询表格输出规范

当用户查询涉及对比、比较、区别（如"A 和 B 区别""对比 X 与 Y""A vs B""比较一下"）时，按本规范输出。

## 输出结构

1. 以 Markdown 表格作为主要输出形式，表格前可有一句引导语
2. 表格列：第一列为「对比维度」，后续每列为一个对比选项（从查询或检索结果中提取）
3. 每个数据格必须附引用 `[内容摘要](content://N)`，N 为检索到的收藏条目 ID
4. 维度按重要性从上到下排列，最关键的差异放前几行

## 维度选取

- 优先从用户查询中提取对比维度（如"价格""口味""位置"）
- 用户未指定维度时，从检索到的收藏条目中归纳 3-6 个关键对比维度
- 每个维度必须有至少一条收藏条目支撑，禁止编造
- 对比选项不超过 5 个，超出时取最相关的并说明取舍

## 引用要求

- 表格中每个非空数据格必须包含至少一个 `content://N` 引用
- 引用指向检索到的真实收藏条目，禁止臆造 ID
- 表格后附「详细条目」列表，展开引用条目的标题与摘要

## 边界处理

- 某选项在某维度无数据：填"暂无相关收藏"，不留空格
- 检索到的条目不足以支撑对比：先说明"当前收藏中相关内容较少"，再给出有限对比或建议补充收藏
- 单一选项无对比对象：不触发本规范，按常规问答处理
- 用户明确要求其他格式（如"用文字描述"）：遵从用户意图，不强制表格
